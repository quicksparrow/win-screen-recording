# 🎬 Screen Recorder Studio
> Record your screen. Make it look good. No basic editing needed.

## What is this?
Screen Recorder Studio is a desktop app for recording your screen with a polished look from the start.  
Instead of recording first and fixing it later, you can preview your setup, adjust layout/webcam/background, then hit record.

## Why this exists
Most screen recorders feel either too basic or too complicated.  
This app focuses on a sweet spot:
- Simple to start
- Enough control to look professional
- Clean output without timeline editing

## Features
- 🎥 Record entire screen, window, or tab
- 🖼️ Live preview before recording
- 📐 Multiple recording formats: Standard 16:9, Vertical 9:16, Square 1:1
- 🎙️ Capture system audio and microphone
- 📷 Webcam support (small overlay or full screen)
- ✨ Enhance webcam (face smoothing + brightness/exposure)
- 🎨 Switch app backgrounds
- 🌙 Light and Dark mode
- ⚡ Fast flow: set up, record, export

## How it works
1. Choose what you want to record
2. Adjust layout (webcam, size, background)
3. Hit record and export

## 💻 Platform
- Currently built for **Windows**
- Packaged as a `.exe`
- Designed and optimized for Windows desktop use

## Installation / Download
- Download the latest `.exe` from this repo’s **Releases**
- Run the installer
- Open the app and start recording

## 🛠️ Built with
- **Electron** for the desktop app shell
- **React** + **TypeScript** for the UI
- **Tailwind CSS** for styling
- **FFmpeg** for local export processing
- **Web APIs** (`MediaDevices`, `Canvas`, `MediaRecorder`, `Web Audio`) for capture/composition
